# Synthetic lab reports

Realistic, **fictional** lab reports for evaluating extraction (Sprints 2–3) and trend analysis (Sprint 4). Each report is a PDF plus a JSON file with its exact ground truth. Every page carries the footer *"SYNTHETIC REPORT generated by Nabz for software testing. Not a medical record."* Lab, doctor and patient names are fictional.

`samples/` holds 9 committed examples. Generate the full evaluation set (git-ignored) with:

```bash
docker compose exec api python -m tools.synthetic --count 500 --histories 50 --visits 4 --seed 42
```

On Git Bash for Windows, prefix `docker compose exec` commands that contain absolute container paths with `MSYS_NO_PATHCONV=1`.

## What varies

| Dimension | Values |
|---|---|
| Layout | `table` (columns with a flag column) · `boxed` (grid, flag as "(H)") · `leaders` (dotted leaders, bracketed ranges) |
| Unit style | `conventional` (Indian: /cumm, lakhs/cumm, million/cumm) · `international` (10^3/µL) · `si` (mmol/L, µmol/L, nmol/L) |
| Unit spelling | e.g. g/dL · gm/dL · gm% · mg% · IU/L · mIU/L · mEq/L |
| Range format | `13.0 - 17.0`, `13.0–17.0`, `13.0 to 17.0`, `< 200`, `Up to 40`, `> 40`, `Desirable: < 200` |
| Test names | Aliases from the catalogue (SGPT / ALT, TLC, PCV, …) |
| Persona | Sex, age 22–78, 0–2 conditions: prediabetes, diabetes, iron deficiency, fatty liver, hypothyroid, early CKD, vitamin D or B12 deficiency, dyslipidaemia, infection; rarely a critical potassium |
| Packages | Comprehensive health check, diabetes care, anaemia, basic, liver & kidney, thyroid, fever panel |

Derived values are computed so each report is internally consistent: Friedewald LDL, VLDL = TG/5, CKD-EPI 2021 eGFR, globulin and A/G ratio, indirect bilirubin, eAG from HbA1c, MCV/MCH/MCHC, a differential summing to 100 %, and transferrin saturation.

**History mode** (`hist-*`) produces several yearly reports for one person. Values vary around a personal baseline by within-subject variation, and one test drifts at a planted slope (`planted_trend` in the JSON).

## Ground-truth JSON (per report)

```jsonc
// abridged from samples/syn-2026-0003.json
{
  "id": "syn-2026-0003", "synthetic": true, "layout": "table", "unit_style": "si",
  "persona": {"sex": "female", "age": 34, "conditions": []},
  "collected_at": "2024-10-12", "pages": 1, "page_size_pt": [595.28, 841.89],
  "rows": [{
    "test_code": "glucose_fasting",       // catalogue code
    "printed_name": "FPG", "printed_value": "4.2", "printed_unit": "mmol/L",
    "printed_range": "3.9 to 5.5", "flag": "",
    "value_canonical": "75.6672",         // canonical unit (mg/dL)
    "ref_low": "70.2624", "ref_high": "99.0880",
    "page": 0, "bbox": [40, 449.0, 555.3, 461.0]   // x0, top, x1, bottom in PDF points, top-left origin
  }]
}
// history reports (samples/hist-2026-00-v1.json) also carry:
//   "person_id": "hist-2026-00", "visit": 1, "planted_trend": {"test_code": "creatinine", "slope_per_year": 0.12}
```

`manifest.csv` lists every report with its layout, unit style, package, persona and row count.
