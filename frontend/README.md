# Nabz web app

Scaffolded in **Sprint 3** (see [docs/07-project-plan.md](../docs/07-project-plan.md)).

Planned stack: React + TypeScript + Vite, react-three-fiber / drei / postprocessing for the 3D body map, Tailwind CSS, Recharts, i18next (English, Hindi, Odia). It runs as the `web` service in `compose.yaml` using a `node:22-alpine` image, so no local Node install is needed.
